# Archived Report Builders

These are the **historical Python scripts** used during the educational project to create Task 3 and Task 4 Word documents.

- `build_citi_task3.py`: original structured-note report generator.
- `build_citi_risk.py`: original three-scenario risk-management report generator.

**Important:** The archived scripts use absolute output paths from the original working environment (`/mnt/data`) and are retained **as process documentation**, not as part of the portable main analysis pipeline. Run [`scripts/run_analysis.py`](../../scripts/run_analysis.py) for cross-platform model and chart reproduction.

The standalone historical document generator for Task 2 is not preserved, but Task 2's formulas and numerical results are implemented by the modular code in [`src/coffee_quant/`](../../src/coffee_quant/).
