# Quantitative Finance Glossary — Coffee Case

| Term | Meaning in this repository |
|---|---|
| Spot price | Current cash price reference for coffee, expressed as USD per pound |
| Futures contract | Standardized exchange-traded contract for a future purchase/sale or settlement |
| Cost of carry | Financing and storage costs, net of any convenience yield, incorporated into a forward price approximation |
| Convenience yield | Economic value of having physical inventory immediately available |
| Contango | Futures curve with more distant contracts generally priced above nearer ones, depending on market context |
| Backwardation | Futures curve with distant contracts generally below nearer ones |
| Strike | Exercise/reference price specified by an option or structured payoff |
| Call option | Right, but not obligation, to buy or receive the specified upside payoff |
| Put option | Right, but not obligation, to sell or receive the specified downside payoff |
| Black-Scholes | Standard European spot-underlying option-pricing benchmark under idealized assumptions |
| Black-76 | European option pricing formula when the underlying reference is a futures/forward contract |
| Delta | Sensitivity of derivative value to a change in the underlying price |
| Vega | Sensitivity of derivative value to a change in volatility |
| Volatility | Statistical dispersion of returns, typically annualized in this case |
| GBM | Geometric Brownian motion, a continuously evolving stochastic positive-price process |
| Risk-neutral measure | Mathematical measure used for no-arbitrage discounted payoff valuation, not a real-world probability forecast |
| Monte Carlo | Numerical simulation by repeatedly sampling random outcomes from specified model assumptions |
| Basis risk | Risk that physical coffee prices and futures reference prices do not move perfectly together |
| Hedging | Reducing a defined exposure using offsetting positions or other contractual protections |
| Tracking error | Variability of differences between a fund's returns and its target benchmark |
| Structured note | Debt instrument combining issuer credit with a contractually specified payoff linked to an underlying |
| Digital option | Option with a fixed payoff if a defined condition is satisfied |
| Value at Risk (VaR) | Quantile-based modeled loss threshold at a specified confidence level and horizon |
| Expected Shortfall / CVaR | Expected loss beyond the defined tail quantile, under the selected model |
| Stress test | Portfolio evaluation under severe but plausible scenarios, which need not have calibrated probabilities |
| PD / LGD / EAD | Probability of default, loss given default, and exposure at default |
| Expected credit loss | Simple framework `PD × LGD × EAD` under consistent assumptions |
| Counterparty | Other party to a financial or physical contractual obligation |
| Margin | Collateral or payment requirement arising from positions or clearing arrangements |
| Operational risk | Risk of loss from failures of processes, people, systems or external disruptions |
| Reconciliation | Checking that orders, executions, cleared trades and accounting records agree |
